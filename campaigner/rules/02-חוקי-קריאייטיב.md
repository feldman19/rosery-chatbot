# ROSERY — חוקי קריאייטיב וקופי

## קופי
- כל הקופי בעברית בלשון זכר תמיד (חריג: "מתנה לה" הפונה לקונה גבר).
- אין אימוג'ים בכותרות.
- אין סופרלטיבים ואין טענות מומצאות ("בסט סלר" וכד').
- לא להבליט חומרים ("נירוסטה" נשמע זול).
- CTA קבוע: "קנה עכשיו".
- שפת ההצעה בכותרת (Headline), לא בטקסט הראשי.
- לכבות Text Improvements וכל שיפורי Advantage+ לפני פרסום (לא נקרא חזרה ב-API — לכבות ידנית בבאלק-אדיט בכל קמפיין).
- שכפול מודעות: תמיד "Use Existing Post" עם Post ID לשימור הוכחה חברתית; להשהות מקור רק אחרי שהחדש חי.

## בלאקליסט קבועה
- זווית בירול (כשל מתועד בכמה וריאציות)
- קרוסלות
- עותקים של סטטי ללא כיתוב שהתעייף
- פתיחות וידאו של אווירה בלבד
- פריימים פותחים של לוגו / מוצר סטטי / קופסה
- מודעות עם תווית "וריאציה" (עריכה מחדש) — תת-ביצוע עקבי

## עובדות חנות לקופי
- משלוח חינם מעל ₪350 · משלוח עד 3 ימי עסקים · החזרות חינם עד 14 יום · 10,000+ ביקורות
- אסט ידוע עם שגיאה: "SING UP FOR AN EXTRA 5% OFF" (צ"ל SIGN UP)

## אילוצי API
- טקסט קריאייטיב לא ניתן לעריכה אחרי יצירה — קריאייטיב חדש + מודעה חדשה.
- asset_feed_spec: CTA חייב גם ב-object_story_spec.link_data.call_to_action + link_data.link; לאמת ב-ads_get_creatives.
- וידאו ב-API דורש thumbnail טרי מ-ads_get_creatives.
- מודעות asset_feed_spec מוצגות ריקות בעורך Ads Manager — שמירה משם מוחקת קופי.
